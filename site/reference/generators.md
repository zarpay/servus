# Generators Reference

Servus generators help teams start new framework artifacts with a consistent structure.

| Command | Purpose |
| --- | --- |
| `rails g servus:service namespace/action` | Generate a new service and related files |
| `rails d servus:service namespace/action` | Remove a generated service |
| event-handler generation commands | Create a handler and matching test scaffold where configured |

For a fuller explanation of why these generators matter, see [Rails Generators](/rails/generators).
