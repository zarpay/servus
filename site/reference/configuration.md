# Configuration Reference

This page is a compact lookup for the main Servus configuration areas used in Rails applications.

| Area | Purpose |
| --- | --- |
| Schema root | Controls where file-based schemas are resolved |
| Schema cache | Controls schema reuse |
| Logging | Sets the visibility of service execution in application logs |
| ActiveJob integration | Enables and tunes async execution |
| Guards and events | Controls loading and validation behavior |

Use the narrative [Rails Configuration](/rails/configuration) page when you want explanation. Use this page when you already know what concept you are looking for.
